# Code（超声波版本）硬件说明

## 1. 版本定位

`Code` 为当前实物调试主版本，使用 HC-SR04 自动开盖。

## 2. 当前引脚与接口（按实物）

- `PA0` -> 蜂鸣器控制（低电平触发，接 `SG90_1 SIGNAL`）
- `PA4` -> JS1 满溢传感器输入
- `PA5` -> HC-SR04 ECHO（接 JS2 SIGNAL）
- `PA6` -> 舵机 PWM（`TIM3_CH1`，接 JS3 SIGNAL）
- `PA7` -> HC-SR04 TRIG（飞线）
- `PB10/PB11` -> OLED 软件 I2C
- `PB0` -> 继电器控制

## 3. 供电建议

- 蜂鸣器模块：建议 `VCC=3.3V`
- 舵机：按当前板卡实际接法运行（动作后程序会停止 PWM 以减载）
- HC-SR04：`VCC=5V`

## 4. 软件关键点

- 自动模式：距离阈值触发开盖
- 满溢检测：启动忽略 12s，连续 3s 才报警
- OLED：批量刷新，减少显示期间输入阻塞
- 开盖优先级高于紫外：紫外运行时开盖会先停紫外
- 手动模式紫外纯手动：不再自动触发消毒
- KEY6 在消毒页也可切换模式（会先停紫外）

## 5. 备注

当前版本为“实物稳定优先”的映射，接口与早期文档不同，请以本文为准。
