# Code（超声波版本）硬件调试检查清单

## A. 上电前

- [ ] 5V、3.3V 电压正常
- [ ] 所有模块共地
- [ ] Type-C 供电稳定

## B. 接线核对（当前实物映射）

- [ ] 蜂鸣器：`PA0 (SG90_1 SIGNAL)`，低电平触发，建议 `VCC=3.3V`
- [ ] 舵机：`PA6 (JS3 SIGNAL, TIM3_CH1)`
- [ ] HC-SR04：`PA5=ECHO`，`PA7=TRIG(飞线)`，`VCC=5V`
- [ ] 满溢传感器：`PA4 (JS1)`
- [ ] OLED：`PB10/PB11`

## C. 功能测试

1. 上电后 OLED 是否稳定显示
2. 按键切换模式是否及时响应
3. 自动模式手靠近 HC-SR04 是否开盖
4. 蜂鸣器是否只在提示/报警时响
5. 满溢触发是否需连续约 3 秒
6. 消毒运行中按 KEY1 是否仍可开/关盖（应可，并优先执行）
7. 消毒页面按 KEY6 是否可切换模式（应可，并先停紫外）

## D. 现象与处理

- 蜂鸣器异常常响：优先检查 VCC 是否为 3.3V、IO 是否接 PA0
- 按键响应慢：确认已烧录最新 OLED 批量刷新版本
- 超声波无触发：优先检查 PA7 飞线
