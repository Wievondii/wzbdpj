# 智能停车场系统固件代码

## 项目概述

基于 STM32F103C8T6 单片机的智能停车场管理系统固件代码。

## 系统功能

1. **车位检测与计数统计**
   - 支持3个车位的实时检测
   - 采用反射式红外避障模块检测车位占用状态
   - 自动统计空余车位数量

2. **车辆进出识别与道闸控制**
   - 入口和出口各配置一个红外传感器检测车辆
   - SG90舵机驱动道闸实现自动开启/关闭
   - 支持缓启缓停，保护舵机

3. **手动与自动模式切换**
   - 自动模式：检测到车辆自动开启道闸
   - 手动模式：通过按键控制道闸开关

4. **异常报警功能**
   - 车位已满时触发声光报警
   - 蜂鸣器+LED组合报警
   - 紧急放行模式

5. **本地数据显示与参数设置**
   - OLED显示屏实时显示系统状态
   - 支持车位总数设置
   - 显示入口/出口道闸状态

## 硬件配置

### MCU
- **型号**: STM32F103C8T6
- **主频**: 72MHz
- **Flash**: 64KB
- **RAM**: 20KB

### 引脚分配

#### 车位检测红外传感器
- JS5 (车位1): PB2
- JS8 (车位2): PB4
- JS10 (车位3): PB6

#### 入口/出口检测红外传感器
- JS11 (入口): PA0
- JS12 (出口): PA1

#### 舵机控制 (SG90)
- 入口道闸: PA2 (TIM2_CH3)
- 出口道闸: PA3 (TIM2_CH4)

#### OLED显示屏
- SCL: PA8
- SDA: PA9

#### 报警系统
- 蜂鸣器: PA4
- LED报警灯: PA5

#### 按键
- SW2 (模式切换): PB12
- SW3 (入口道闸): PB13
- SW4 (出口道闸): PB14
- SW5 (紧急放行): PB15
- SW6 (菜单确认): PA11
- SW7 (增加车位): PA12
- SW8 (减少车位): PA15

## 编译说明

### 使用 Keil MDK
1. 打开 Keil uVision
2. 创建新工程，选择 STM32F103C8 芯片
3. 添加所有源文件到工程
4. 配置编译选项
5. 编译生成 HEX 文件

### 使用 Makefile (需要 ARM GCC 工具链)
```bash
# 编译
make

# 清理
make clean
```

## 工作流程

### 自动模式
1. 系统实时检测车位占用状态
2. 车辆到达入口触发红外传感器
3. 系统检查是否有空余车位
4. 有空位则自动开启入口道闸
5. 车辆通过后5秒自动关闭道闸
6. 车位计数器更新
7. 车辆离开时触发出口传感器
8. 自动开启出口道闸
9. 车辆通过后5秒自动关闭道闸
10. 空余车位数增加

### 手动模式
1. 管理员通过按键手动控制道闸
2. SW3控制入口道闸开关
3. SW4控制出口道闸开关
4. 车位状态仍然自动检测和显示

## 注意事项

1. **舵机供电**: SG90舵机工作电压为5V，需要外部供电，不可从STM32的3.3V引脚取电
2. **传感器配置**: 红外传感器需要根据实际安装高度调整检测距离
3. **消抖处理**: 所有传感器都实现了软件消抖，防止误触发
4. **电流保护**: 舵机采用缓启缓停，避免瞬间电流过大
5. **JTAG禁用**: 代码中禁用了JTAG接口，释放PB3/PB4/PA15作为GPIO使用
