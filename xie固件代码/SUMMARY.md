## 四、编译说明

### 方法一：使用 Keil MDK

2. File -> New Project -> 选择 STM32F103C8
3. 添加所有.c文件到工程
4. 配置 Include Paths
5. 编译生成 .hex 文件

```bash
cd xie固件代码

make
```

## 八、注意事项

### 硬件注意事项
1. **舵机供电**: 必须使用外部5V电源，不可从STM32取电
2. **传感器调节**: 根据实际安装高度调整红外传感器检测距离
3. **共地连接**: 舵机电源GND必须与STM32 GND共地
4. **JTAG禁用**: 代码已禁用JTAG，释放PB3/PB4/PA15为GPIO

### 软件注意事项
1. **延时函数**: 使用systick实现精确延时
2. **中断优先级**: 系统配置了合理的中断优先级
3. **防抖处理**: 所有传感器都有软件消抖
4. **状态机**: 主程序采用状态机设计，逻辑清晰
